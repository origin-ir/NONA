# نونا • nona (اپلیکیشن آرامش، ذهن‌آگاهی و کارت‌های جادویی)

اپلیکیشن اندروید **نونا (nona)** یک همراه روزانه برای مراقبه، تنفس آگاهانه، کاهش اضطراب و جمع‌آوری کارت‌های حکمت و آرامش است که با **Jetpack Compose** و معماری مدرن اندروید توسعه داده شده است.

---

## ✨ ویژگی‌های کلیدی

- 🪷 **مأموریت‌های روزانه آرامش (Daily Zen Tasks)**: تمرین‌های کوچک و کاربردی شامل تنفس ۴-۴-۴، مکث در لحظه حال، نوشتن حس و شکرگزاری روزانه.
- 🌬️ **گوی تنفس کیهانی (Breathing Oasis)**: ریتم بصری آرامش‌بخش با هدایت دقیق زمان‌بندی و بازخورد هپتیک (ویبره لمسی).
- 🎴 **کارت‌های جادویی کلکسیونی (Magic Collectible Cards)**: کسب کارت‌های عرفانی با درجات مختلف کمیابی (عادی، کمیاب، حماسی، افسانه‌ای و کیهانی) پس از اتمام مأموریت‌ها.
- 🔄 **نمایش و چرخش سه‌بعدی کارت‌ها (3D Flip Animation)**: امکان لمس و چرخش ۳۶۰ درجه کارت‌ها برای مطالعه حکمت، پیام روز و اشتراک‌گذاری/کپی آن.
- 🎵 **اصوات آرامش‌بخش طبیعت و فرکانس‌های ذن**: پخش پس‌زمینه باران شبانه، جنگل، امواج دریا و فرکانس ۴۳۲Hz.
- 🌌 **طراحی مدرن کیهانی (Cosmic Material 3 Theme)**: تایپوگرافی دلنشین فارسی، رنگ‌بندی آرامش‌بخش و پشتیبانی از تم تاریک.
- 💾 **پایداری داده‌ها (Room Database)**: ذخیره امن سوابق، امتیازات و کارت‌ها به صورت کاملاً آفلاین.

## 📥 دانلود فایل نصبی (APK)

شما می‌توانید فایل APK آماده نصب را به دو روش دریافت کنید:

### ۱. از طریق منوی AI Studio (مستقیم)
در پنل بالای AI Studio، روی آیکون **Settings / Export** کلیک کنید و گزینه **Generate APK** یا **Download ZIP / Push to GitHub** را انتخاب نمایید.

### ۲. از طریق GitHub Releases یا Artifacts
با پوش کردن این مخزن به گیت‌هاب:
1. در تب **Actions**، گردش کار خودکار فعال شده و فایل APK ساخته می‌شود.
2. با ایجاد یک تگ یا انتشار Release (مثلاً `v1.0.0`)، فایل `app-debug.apk` به صورت خودکار در بخش **Releases** گیت‌هاب برای دانلود عمومی قرار می‌گیرد.

## 🚀 راهنمای ساخت و اجرا با کد منبع

### پیش‌نیازها:
- Android Studio Ladybug یا نسخه‌های جدیدتر
- JDK 17 یا بالاتر
- Android SDK با حداقل نسخه 24 (`minSdk 24`)

### دستورات کامپایل:
```bash
# کلون کردن پروژه
git clone https://github.com/your-username/nona-zen-app.git
cd nona-zen-app

# ساخت فایل نصبی دیباگ
./gradlew assembleDebug

# اجرای تست‌های یونیت
./gradlew testDebugUnitTest
```

فایل نهایی در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## 🛠️ ساختار فنی (Tech Stack)
- **UI Framework**: Jetpack Compose (Material 3)
- **Language**: Kotlin 2.x
- **Architecture**: MVVM + Clean Architecture
- **Local Persistence**: Room Database (SQLite) with KSP
- **Asynchronous**: Coroutines & StateFlow
- **Automation**: GitHub Actions CI/CD Pipeline
